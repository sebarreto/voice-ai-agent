# Voice AI Agent – Azure + Vector Search

This project is a prototype voice AI assistant with:

- Python backend (Flask)
- Azure OpenAI
- Azure Cognitive Search (vector DB)
- Azure Speech (STT + TTS)
- HTML/JS frontend

## Architecture

Frontend (HTML + Speech SDK)
→ Flask API
→ Azure OpenAI
→ Azure Cognitive Search (vectors)

## Setup

1. Clone repo
2. Create virtual environment
3. Install dependencies
4. Configure `.env`
5. Run backend

See `setup.md` for detailed steps.
